# PHASE 7 — Explainability (Production XAI)

> *A verdict no human can audit is an oracle, not evidence. ARGUS's explanation layer is a first-class output, designed for journalists, moderators, analysts, and courts — not for ML engineers.*

## 7.1 What the XAI layer must output

```json
{
  "authenticity_score": 0.23,        // calibrated P(authentic capture)
  "trust_score":        0.61,        // epistemic quality of the evidence
  "risk_score":         0.78,        // decision-facing manipulation risk
  "verdict_band":       "LIKELY MANIPULATED — MEDIUM-HIGH CONFIDENCE",
  "evidence_ranking": [
    {"module":"physics_shadow",  "direction":"synthetic","contribution":+0.34,"reliability":0.82,"plain":"Shadows fall in two incompatible directions for a single sun."},
    {"module":"retrieval",       "direction":"synthetic","contribution":+0.20,"reliability":0.77,"plain":"A near-identical image appears in an AI-art gallery posted last week."},
    {"module":"semantic_anatomy","direction":"synthetic","contribution":+0.12,"reliability":0.55,"plain":"The left hand has six fingers."},
    {"module":"metadata",        "direction":"neutral",  "contribution": 0.00,"reliability":0.05,"plain":"No camera metadata present (image was likely re-saved)."}
  ],
  "contradictions": [
    {"between":["metadata_claim_2024","retrieval_2019_original"],
     "severity":0.7,
     "plain":"File claims 2024 but a matching image existed online in 2019."}
  ],
  "silenced_modules": ["prnu","cfa","frequency_peaks"],  // with reasons
  "human_readable":  "This image is likely manipulated... (full NL narrative)",
  "limitations":     "Low-resolution screenshot; sensor-level forensics unavailable."
}
```

## 7.2 Five layers of explanation (audience-tiered)

1. **The three scores + verdict band** — the at-a-glance triage (a moderator's 2-second read).
2. **Evidence ranking** — every module's *signed, reliability-weighted contribution* to the posterior log-odds, sorted by magnitude. Green = supports authentic, red = supports synthetic, grey = silenced/neutral. This is directly readable off the Bayesian core (LLR contributions) and cross-checked with SHAP from the correction head.
3. **Visual / localized evidence** — heatmaps and overlays a human can verify *with their own eyes*: JPEG-ghost splice maps, the drawn inconsistent shadow rays, the six-finger crop, the lighting-direction arrows, the reverse-image match thumbnails. **Pixel-grounded explanation is the trust multiplier.**
4. **Contradiction report** — explicit conflicting evidence with severity and plain-language framing. This is unique to ARGUS and is precisely what an analyst needs.
5. **Natural-language narrative** — a 3–5 sentence verdict that *narrates the evidence chain*, names the limitations, and never overstates. Generated by an LLM (Gemini / Groq-hosted) constrained to **only** reference the structured evidence above (no free-form speculation), with a templated fallback when no LLM is available.

## 7.3 How it is implemented

- **Evidence ranking** is *native*, not post-hoc: the Bayesian fusion core already decomposes the posterior into additive per-module LLR contributions. We simply expose them. The LightGBM head's **SHAP** values provide a second, interaction-aware attribution; large disagreements between the two are themselves surfaced as an uncertainty flag.
- **Reliability transparency:** every cited cue shows its reliability, and **silenced modules are listed with the reason** ("PRNU unavailable: image is a low-resolution screenshot"). Telling the user *what you could not check* is as important as what you could.
- **Localization** comes free from the forensic modules that already produce spatial maps (JPEG, CFA, noise, ELA) and from the physics/semantic modules (shadow rays, bounding boxes around anatomy errors).
- **Faithfulness guarantee:** because the LLM is *grounded* — it receives only the structured evidence JSON and is instructed to paraphrase, not infer — the narrative is **faithful by construction**. We additionally run a faithfulness check: every claim in the narrative must map to an evidence item, or it is rejected and the template fallback is used.
- **Calibrated language:** verdict bands map deterministically from (authenticity, trust): e.g., high-authenticity+low-trust → *"Appears authentic, but evidence is limited — treat as inconclusive."* This prevents the LLM from inventing confidence the numbers don't support.
- **Audit log:** the full evidence JSON + model versions + timestamps is persisted, so any verdict is reproducible and contestable — a hard requirement for legal/journalistic use.

## 7.4 Why this beats a saliency map

Incumbent XAI is a Grad-CAM heatmap over a black-box classifier — it shows *where* the model looked, not *why* a human should agree, and it inherits the classifier's OOD unreliability. ARGUS's explanation is **a chain of independent, human-verifiable forensic facts with explicit reliabilities and contradictions** — the difference between "the model attended to the cheek" and "the shadows are physically impossible and an earlier copy exists online from 2019."

# PHASE 8 — MVP Design (3 months, commodity hardware, open-source only)

> *The smallest ARGUS that proves the thesis: reliability-aware fusion of orthogonal, mostly generator-agnostic evidence beats a single classifier — especially under laundering and on unseen generators.*

## 8.1 MVP scope decision

**In-scope (proves the thesis):** the reliability layer, calibrated Bayesian+LightGBM fusion, tri-axial output, XAI, and ~8 evidence modules spanning all tiers. **Out-of-scope (v2):** full PRNU with reference device, latent inversion, multi-view physics, video. The MVP must demonstrate *graceful degradation + open-set abstention + explained verdicts*, not maximal benchmark accuracy.

## 8.2 Exact modules (8 for the MVP)

| # | Module | Tier | Method / library | Why in MVP |
|--:|--------|:----:|------------------|-----------|
| 1 | **Provenance/C2PA + Metadata** | A | `c2pa-python`, `exiftool`/`exifread`, `pillow` | Cheapest, highest-value positive evidence + self-silencing demo |
| 2 | **Retrieval / embedding** | A | `open_clip` (ViT-B/32) + `faiss` over a built index; `imagehash` (pHash) | The open-set backbone; demonstrably generator-agnostic |
| 3 | **JPEG forensics (DQ + ghosts + grid)** | A | custom NumPy/OpenCV (DCT, blocking) | Cheap splice localization + heatmaps |
| 4 | **ELA (error-level analysis)** | A | Pillow recompress diff | Classic, explainable tamper map |
| 5 | **Frequency / azimuthal spectrum** | C | NumPy FFT + radial average | Cheap known-generator corroboration; demos OOD-gating |
| 6 | **Noise / residual consistency** | A | wavelet/median residual (`PyWavelets`, OpenCV) | Tamper + "too-clean" signal |
| 7 | **Physics + Semantic (VLM-assisted)** | A/B | open VLM (`Qwen2-VL`/`LLaVA`-class, or Gemini/Groq via API) for lighting/shadow/anatomy consistency prompts | Durable backbone; the open-set hero |
| 8 | **Learned fakeness probe (OOD-gated)** | C | a CLIP-linear-probe trained on open data; Mahalanobis OOD score | One *demoted, self-silencing* classifier to contrast against the field |

**Reliability layer:** quality profiler (resolution, JPEG-Q estimate, double-compression, blur, screenshot heuristic) + per-module degradation transfer functions (calibrated by the degradation sweep) + per-learned-module Mahalanobis OOD score.

**Fusion:** Bayesian LLR core (isotonic per-module calibration) + LightGBM correction head + conformal abstention. **XAI:** native LLR ranking + SHAP + heatmaps + grounded LLM narrative.

## 8.3 Exact open-source models & libraries

- **Vision/ML:** PyTorch, `open_clip_torch` (CLIP ViT-B/32), `timm`, optional `DINOv2`; an open VLM (Qwen2-VL-2B/7B or LLaVA) *or* Gemini/Groq API for the physics/semantic narrative (user is providing a key).
- **Forensics/DSP:** OpenCV, NumPy, SciPy, `PyWavelets`, Pillow, `scikit-image`.
- **Provenance/metadata:** `c2pa-python`, `exiftool`, `exifread`, `piexif`.
- **Retrieval:** `faiss-cpu`, `imagehash`.
- **Fusion/calibration:** `lightgbm`, `scikit-learn` (isotonic/Platt), `mapie` or `crepes` (conformal), `shap`.
- **OOD:** `pytorch-ood` or hand-rolled Mahalanobis/deep-kNN.
- **Serving:** FastAPI + a job queue; React dark "forensic console" UI; MongoDB for audit logs.
- **All CPU-runnable**; a single commodity GPU optional for the VLM and CLIP (or use the hosted API).

## 8.4 Dataset strategy (no proprietary data, no large-scale fine-tuning)

1. **Authentic pool:** open camera-image sets (RAISE, Dresden, public Flickr-CC, FFHQ for faces) — for camera-pipeline/noise calibration and the authentic class.
2. **Synthetic pool:** *only publicly available* generators' outputs (open SD/SDXL/Flux samples, public GAN sets, GenImage/DiffusionForensics-style public corpora) — strictly to train the *demoted* probe and to calibrate, **never** as the system's backbone.
3. **The crucial split — Leave-One-Generator-Out (LOGO):** train on a subset of generators, **test on entirely held-out generators**. This is the only split that measures the property we care about (open-set generalization). Benchmark accuracy on seen generators is reported but de-emphasized.
4. **Self-supervised degradation calibration:** take authentic images, apply a grid of (JPEG-Q, downscale, screenshot-sim, double-compression) and measure each module's accuracy vs. degradation → fit the reliability transfer functions. **No labels beyond authentic/synthetic needed; fully reproducible.**
5. **Laundering test set:** push a held-out set through real platform pipelines (or faithful simulators) to measure robustness curves.

## 8.5 Evaluation methodology

- **Primary metrics:** (1) **LOGO AUROC** (unseen-generator generalization); (2) **ECE / reliability diagrams** computed *separately on laundered vs. pristine* subsets; (3) **selective risk / risk–coverage curves** — accuracy when allowed to abstain (ARGUS's signature advantage); (4) **robustness curves** vs. JPEG-Q and downscale; (5) **explanation faithfulness** (do removed top cues change the verdict as predicted?).
- **Baselines:** a single XceptionNet/CLIP-probe detector — to demonstrate ARGUS's superior *calibration under shift* and *graceful degradation*, even where raw seen-generator accuracy is comparable.
- **Headline success criteria:** ARGUS shows (a) **far lower ECE under laundering**, (b) **higher selective accuracy at fixed coverage**, (c) **non-trivial LOGO performance where the single classifier collapses to chance**, and (d) **human-rated explanation usefulness**. Note: the win is *calibration + honesty + explainability*, not necessarily a higher single accuracy number — by design.

## 8.6 3-month plan

- **Weeks 1–3:** ingest + quality profiler + metadata/C2PA + JPEG/ELA + frequency + noise modules (all classical, fast wins) + module contract + audit store.
- **Weeks 4–6:** CLIP retrieval index + embedding module; degradation sweep → reliability transfer functions; per-module isotonic calibration.
- **Weeks 7–9:** VLM physics/semantic module; OOD-gated learned probe with Mahalanobis; Bayesian fusion core + LightGBM head + conformal abstention.
- **Weeks 10–12:** XAI layer (LLR ranking + SHAP + heatmaps + grounded LLM narrative); React forensic-console UI; LOGO + laundering + selective-risk evaluation; write-up.
